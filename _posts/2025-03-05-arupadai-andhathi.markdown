தமிழ் கடவுள் முருகன் குடிகொண்ட அறுபடைவீடுகளைப் பற்றி பாட நெடுநாள் அவா கொண்டமையால், அடியேனின் சிறு முயற்சி இது. ஒவ்வொரு பாடலும் ஒவ்வொரு தலத்தின் மேல் நேரிசை வெண்பாவாகவும், இந்நூலை அந்தாதியாகவும் எழுத முயற்சி செய்திருக்கிறேன். தமிழ் மீதும் கொண்ட தீராக்காதலில், இதை செய்ய எத்தனித்தேன்.

<!-- more -->

அந்தாதி என்பது அந்தம் + ஆதி எனும் இரு சொற்சேர்க்கையால் உருவானது. ஒரு பாடலின் நிறைவில் வரும் எழுத்தோ, சீரோ, சொல்லோ அடுத்த பாட்டின் முதலில் வருவது அந்தாதி எனப்படும். அதைப்போல், நிறைவுப் பாட்டின் நிறைவு சொல், முதல் பாடலின் தொடக்கமாக அமைவது போல் முடிந்த வரையில் பின்பற்றி, முயற்சி செய்துள்ளேன்.
முருகனின் படைவீடுகளைப் போல் முருகனின் தனித்துவங்கள் ஆறு. வேல், மயில், அழகு, தமிழ், வள்ளி, தெய்வானை என, ஒவ்வொரு பாட்டிலும் ஒரு தனித்துவத்தைப் பற்றியும், அப்படைவீட்டுச் சிறப்பையும் கூற முயற்சித்துள்ளேன்.
பிழைகளோ குறைகளோ இருப்பின், அதைப் பொறுத்து, தவறுகளைச் சு(கு)ட்டிக் காட்டும்படி கேட்டுக்கொள்கிறேன்.

### காப்பு

```
புரிவீரே தேந்தமிழ் பாட்டுக் கிரங்கும்
கரிமுகனே, செய்தேன்முக் கண்ணன் - நெருப்பிற்
பிறந்தோன் அறுபடை பாமாலை இந்நூல்
சிறந்திட நீரே அருள். 
```

இனிமையான தமிழ் பாட்டிற்கு இரங்கிடும் ஆனைமுகனே. முக்கண்ணனான சிவபெருமான் நெற்றிக்கண் நெருப்பில் பிறந்த முருகனின் அறுபடை பாமாலை எழுதுகிறேன். இந்நூல் சிறந்திட நீரே அருள் புரிவீரே. (இது பூட்டுவிற் பொருள்கோள் முறை ஆகும்)

## நூல்

### திருப்பரங்குன்றம்

```
சொற்பன மோநின்கற் சிற்பமோ என்னுடை
கற்பனை யோஎன்யோ கந்தானோ - வெற்பாம்
பரன்குன்றில் கண்டேன் பிராட்டியாம் மங்கை
கரம்பிடித்த கந்தன் கழல்.
```

திருப்பரங்குன்றத்தில் காண்கிறேன் மங்கையாம் தெய்வானை கரம் பிடித்த கந்தனின் கழல். இது என் கனவோ? இது என் கற்பனையோ? இல்லையேல் இது என் யோகமோ?

__திருப்பரங்குன்றம் - முருகன் தெய்வானையை மணந்த திருத்தலம்__

### திருச்செந்தூர்

```
கழன்றன வேஅமரர் கால்தளை யாவுமே
வேழமர் கோனும் தொழுத - எழில்சொரி
செந்தூர் அமர்ந்திடும் சத்திவேல் ஏந்திய
கந்தன் இருகைகற் கண்டு.
```

வேழம் (யானை) மீது அமரும் இந்திரன் வணங்கிய, அழகிய திருச்செந்தூரில் சக்திவேல் தாங்கி நிற்கும் கந்தனின் இரு கைகள் கண்டு, தேவர்களின் காலில் உள்ள (சூரபத்மனால் பூட்டப்பெற்ற) விலங்குகள் யாவும் கழன்றனவே.

__திருச்செந்தூர் - முருகன் தேவர்களைக் காக்க சூரனோடு போர் செய்த திருத்தலம்.__

### பழனி 

```
கற்கண்டும் ஈடாகா கற்றுணர் தீந்தமிழ்
சொற்கொண்டு நின்துதியுஞ் செய்திட்டேன் - வெற்பாம் 
பழனிமலை மேவும் பரம்பொருளே நின்னடி
நிழற்கீழ் நின்றுடுவேன் நான்.
```

கற்கண்டின் இனிமையும் ஈடாகாத இனிமையுள்ள தமிழ்ச்சொற்கள் கொண்டு உன்னைத் துதித்தேன். பழனிமலை மீது ஏறி நின்ற பரம்பொருளே, உனது காலடி நிழலின் கீழே நான் என்றும் நின்றுடுவேன்.

__பழனி - ஞானப்பழத்திற்காக கோபித்து மலைமீது நின்ற திருத்தலம்.__

### சுவாமிமலை 

```
நான்மறை சாரத்தை நாதனுக் கோதியே
வான்புகழ் கொள்திரு வேரகஞ்- சென்று
வியத்தகு பேரழகன் வேலனைக் கண்டால்
மயங்கிடு மேயென் மனம். 
```

நான்கு வேதங்களின் சாரமான பிரணவத்தை தனது தகப்பனான சிவபெருமானுக்கு உபதேசித்ததால் வான் அளவு புகழ் பெற்ற தலமான சுவாமிமலை என்னும் திருவேரகம் சென்று, அங்கு வியக்கவைக்கும் அழகுள்ள வேலன் முருகனைக் கண்டால் என் மனம் மயங்கிடுமே.

__சுவாமிமலை - முருகன் சிவனுக்கு பிரணவப் பொருளை உபதேசித்த திருத்தலம்__

### திருத்தணி

```
மனம்புகுந் தேநம் மதிமயக்குங் காமஞ்
சினம்கொல் தணிகா சலனை - கனங்கரு
கண்ணன் மயிலமர் காந்தன் கடம்பனைக்
காண்பது ஒன்றே கருத்து.
```

நம் மனத்தில் புகுந்து நம் மதியை மயக்கும் ஆசையையும், கோபத்தையும் கொல்லும் தணிகாசலனை, கருத்த பெரிய கண்களைக் கொண்டவனை, மயில்மேல் வீற்ற காந்தம் போன்றவனை, கடம்பனை (கடம்ப மாலை அணிந்தவன்) காண்பது ஒன்றே என் குறிக்கோள்.

__திருத்தணி - முருகன் அசுரர்களை வதைத்த பின் சினம் தணிந்து அமர்ந்த திருத்தலம். இப்பாடலில் நம் உள்ளே உள்ள கோபத்தையும், ஆசையையும் அசுரர்களாக சித்தரித்துள்ளேன்.__

### பழமுதிர்சோலை

```
கருத்த குழலாள் குறவள்ளி நாடும்
விருத்தன் எழில்சோலை வாசன் - பொருநன்
வடிவன் பெருமை உரைத்திட என்றும்
முடிவொன்று உண்டாமோ சொல்.
```

கருத்த கூந்தலை உடைய வள்ளி நாடுகின்ற முதியவர் (வேடமிட்ட முருகன்), அழகிய சோலைமலையில் வாசம் செய்யும் வீரன், வடிவழகன் - அவன் பெருமை கூறத் துவங்கினால் அதற்கு முடிவுதான் உண்டோ, சொல்!

__பழமுதிர்சோலை - முருகன் வள்ளியை மணந்த இடம்__
